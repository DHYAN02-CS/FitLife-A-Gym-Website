# 🏋️ Gym Website

A modern, responsive gym website built using **HTML, CSS, and JavaScript**. The website provides an engaging user experience with dedicated pages for fitness programs, pricing, gallery, shopping cart, and contact information.

## 🌟 Features

- 🏠 Responsive Home Page
- 💪 About Us Section
- 🏋️ Fitness Programs
- 💰 Membership Pricing Plans
- 🖼️ Gallery of Gym Facilities
- 🛒 Shopping Cart Page
- 📞 Contact Form
- 📱 Mobile-Friendly Design
- ⚡ Smooth Navigation and Interactive UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Project Folder

```bash
cd gym-website
```

### 3. Open the Website

Simply open **index.html** in your preferred web browser.

No additional installation or dependencies are required.
